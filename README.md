#  🚗 Projeto Modal - Carros

Uma aplicação web interativa e responsiva desenvolvida para exibição de uma galeria de automóveis. O projeto utiliza **Bootstrap 5** para estilização e **JavaScript nativo (ES6+)** para renderização dinâmica dos cards, controle do modal de detalhes das imagens e alteração de tema (Light/Dark mode).

---

## 🚀 Funcionalidades

- 🏎️ **Galeria Dinâmica de Veículos:** Exibição de cards de carros gerados dinamicamente via JavaScript.
- 🔍 **Modal de Detalhes:** Visualização expandida da imagem e descrição detalhada do veículo selecionado.
- 🌓 **Alternador de Tema (Dark/Light Mode):** Suporte nativo ao tema escuro do Bootstrap com alternância rápida de tema.
- 📱 **Layout Responsivo:** Adaptável a dispositivos móveis, tablets e desktops.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3 / Bootstrap 5 (v5.3.8):** Estilização, layout em grid responsivo e componentes dinâmicos (Modais e Botões).
- **Bootstrap Icons:** Ícones para a interface e alternador de tema.
- **JavaScript (Vanilla / ES6):** Manipulação do DOM e lógica de dados.

## 🎨 Demonstração das Funcionalidades principais

- **Modal Interativo:** Clique em um veículo na galeria para abrir o componente modal contendo a imagem em destaque e sua descrição completa.
